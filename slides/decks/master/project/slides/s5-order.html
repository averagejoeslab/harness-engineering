An order of operations for the body

OperationHow it checks the result
1Files and data, directly: commands and scriptsthe exit code and the result
2The app's own interface: its CLI or APIask the app for its state
3Named controls: accessibility buttons and fieldslist the window's controls
4Pixels, only for what's truly visualcompare a new screenshot with the last

Use the most precise operation that can reach the target, and read the result back. Fall back only when it can't. What it reads back, not what it expected, decides whether it worked.
