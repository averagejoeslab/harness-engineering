Independent commands, at the same time

< Run these three independent commands in parallel, as three separate tool calls in one response: …

$ sleep 5; echo a

  run this? [y/N] y

$ sleep 5; echo b

  run this? [y/N] y

$ sleep 5; echo c

  run this? [y/N] y

$ sleep 5; echo a

  └ a

  … b, c

> They ran in parallel. Each command took about 5.1 seconds, and all three finished at 06:13:00.

  The whole batch took about 5 seconds instead of the roughly 15 it would have taken one after another.

harness engineering · production · performance

Output asks about each, then runs the approved ones together. The model decides what can run at once; the harness just doesn't make them wait. With ThreadPoolExecutor: the approved commands run at the same time, and each result is shown again under its command.
