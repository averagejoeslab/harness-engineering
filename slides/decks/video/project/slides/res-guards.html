Resilience

What if something breaks?

A request fails

Anthropic(max_retries=3)

The model interface retries a failed request up to three times.

A command hangs

timeout 60 sh -c cmd

Output stops every command after a minute, and says so.

It's too long to send

compact(messages, drop)

Control flow catches the “too long” error and summarizes the oldest part.
