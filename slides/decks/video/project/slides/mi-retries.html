Model interface · resilience

A request that fails is retried

client = Anthropic(max_retries=3)  # resilience: retry a request that fails

The API client retries a failed request up to three times before it gives up. A network error or a busy server no longer ends the session.

Everything else about a failing model is control flow's: a crash is a stop, and the diary means the session can resume.
