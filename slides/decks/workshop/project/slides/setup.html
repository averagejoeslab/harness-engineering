export ANTHROPIC_API_KEY=your-key

The task

shop/ is a tiny project with a bug: total() in prices.py should take a percentage discount off a basket, and its test fails.

The request, every time

“The tests are failing. Find out why and fix it.” git checkout . puts the bug back.

harness engineering · building a harness

You need uv, an Anthropic API key, and Docker for the production part. Every command runs from shop. The agent changes the task's files as we go, so git checkout dot resets it. Keep your key in your environment, never in a file you commit.
